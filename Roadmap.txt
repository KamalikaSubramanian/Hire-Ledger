Full User Flow
Step 1: Onboarding

User signs up / logs in (Google or email via NextAuth)
User fills basic profile: Name, email, phone number (for notifications), and optionally connects LinkedIn (for follow-up tracking later)

Step 2: Starting a New Check
3. User clicks "New Application Check" from dashboard
4. User uploads Resume (PDF) — system extracts text in background
5. User uploads or pastes Job Description — system extracts text in background
6. User enters application metadata:

Company Name (e.g., Wipro)
Job Position (e.g., Software Developer)
Job Location
Date of Application (defaults to today, editable)

Step 3: AI Matching
7. User clicks "Analyze Match"
8. AI compares resume text vs JD text and returns:

Match Score (%)
Matched Skills list
Missing Skills list
2–3 improvement suggestions


Result is shown instantly on screen as a summary card (score + skill breakdown)

Step 4: Auto-Logging (system does this automatically, no extra user action)
10. The system saves this check as a log entry under that user, tagged with:
- Company name, position, location, date, resume file, JD text, score, missing skills
11. The missing skills from this check are also pushed into the user's personal "Missing Skills Pool" — a running list aggregated across all their checks (so far, so good — matches your point 7)
Step 5: Interview Prep Generation
12. Immediately after the match result, user sees a button: "Generate Interview Prep for this Role"
13. AI takes the JD + matched/missing skills and generates a topic-wise interview prep list (e.g., "DSA: Arrays & Recursion," "System Design: REST API basics," "Project Deep Dive: explain your MERN e-commerce app")
14. This prep list is saved alongside that specific application log, so it's always tied to that company + role
Step 6: Company-Wise Dashboard (your Meera example)
15. User navigates to "My Applications" page
16. Applications are grouped by Company Name as collapsible cards:
- Wipro (2 applications)
- Software Developer — Applied 12 Jan — Score 74% — [View Resume/JD/Missing Skills/Prep]
- Backend Developer — Applied 15 Jan — Score 68% — [View Resume/JD/Missing Skills/Prep]
17. Clicking any role expands full details: resume used, JD text, score, missing skills, interview prep, and a follow-up log (see next step)
Step 7: Follow-Up Tracking
18. Under each logged application, user can manually mark: "Followed up via Email" or "Followed up via LinkedIn," with a date/timestamp — this builds a follow-up history per application
19. System calculates days-since-application automatically
Step 8: Smart Notifications (AI + rule-based)
20. A background job (cron/scheduled function) checks daily: if an application has had no follow-up logged within X days (e.g., 5–7 days), trigger a notification
21. Notification sent via push notification (web push / PWA) or email, e.g.: "You applied to Wipro (Backend Developer) 6 days ago — consider following up."
22. AI can optionally personalize the notification text (e.g., suggest a follow-up message draft) rather than a generic template
Step 9: Skill Gap Insights (recurring view)
23. User visits "My Missing Skills" page — separate from individual applications
24. Shows an aggregated, ranked list: which skills appear most frequently across all their applications (e.g., "Docker missing in 6/9 applications")
25. This gives the user a prioritized personal learning roadmap, independent of any single company
Step 10: Ongoing Use Loop
26. Every time the user applies to a new role, they repeat Steps 2–5
27. Over time, the dashboard (Steps 6, 9) becomes richer — showing patterns like "your scores are improving," "these are your top 3 recurring gaps," "these are companies you've applied to multiple times"
